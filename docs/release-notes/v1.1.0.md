The first update to Reruns. If you have 1.0.0, it updates itself: Settings → General → **Check now**, then **Update and restart**.

## New look

- **A proper icon** in the taskbar, Start menu, installer and tray, replacing the placeholder.
- **One clean header on Windows.** The Windows title bar is gone, and Reruns' own header has the minimize, maximize and close buttons. Drag it to move the window, and double-click it to maximize.
- **The sidebar tucks itself away** to icons in Settings, in the clip viewer and on narrow windows. Ctrl+B or the sidebar button opens it again.
- **Smooth playback bar.** The progress line follows the video every frame instead of jumping a few times a second.
- **Friendlier dates** on clips: "Today, 10:20 PM" instead of "2026-11-04 22:20".
- The sidebar shows the **reruns.gg** wordmark.

## Recording

- **You can see when recording is failing.** If capture keeps failing in a game, the header says "Can't record <game> · retrying", with the reason when you hover it, instead of "Waiting for a game".
- **Automatic encoder fallback (Windows).** If your graphics encoder refuses to start, for example because another app is using it, Reruns switches to the next encoder that works instead of retrying forever.
- **Better logs for missing audio.** Each saved clip now logs every audio track. If a track is left out, the log says why, which helps track down audio setups like SteelSeries Sonar.

## Fixes

- The icon on clips without a thumbnail no longer hides under the "edited" badge.
- The viewer's time display is spaced properly ("0:02.50 / 0:06.00").
- The Games page no longer says Windows records your whole monitor; it records the game's window.

Found a bug? [Open an issue](https://github.com/lpears0n/reruns/issues) with your log attached (`%LOCALAPPDATA%\gg.reruns.app\logs` on Windows, `~/.local/share/reruns/logs` on Linux).
