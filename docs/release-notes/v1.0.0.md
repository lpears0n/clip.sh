The first release of **Reruns**: an instant replay recorder for games, for Windows and Linux. It keeps the last 30 seconds (or however long you set) in memory while you play. Press **F8** and that moment is saved as an MP4, named after the game.

## Download

| Platform | File |
| --- | --- |
| Windows 10/11 (64-bit) | `Reruns_1.0.0_x64-setup.exe`. GStreamer is bundled, nothing else to install. |
| Linux, any distro | `Reruns_1.0.0_amd64.AppImage` |
| Debian, Ubuntu | `Reruns_1.0.0_amd64.deb` |
| Fedora, openSUSE | `Reruns-1.0.0-1.x86_64.rpm` |

The Windows installer isn't code-signed yet, so SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**.

## Recording

- **Finds your game by itself.** Steam and Wine/Proton games are detected when they start. On Windows, so are games from Epic, Riot, Xbox/Game Pass, GOG, Ubisoft Connect, EA and Battle.net. Recording begins on its own, with no window picker. Apps that aren't games can be ignored.
- **Records only the game's window.** On Windows this uses Windows Graphics Capture, and on KDE Plasma it uses KWin's screencast protocol. Other Linux desktops ask once which screen to record and remember the choice.
- **Hardware encoding:**
  - **Windows:** NVENC, AMD AMF, Intel Quick Sync or Media Foundation.
  - **Linux:** NVENC or VA-API, with x264 as the fallback.
  - The app tests which encoders really work on your PC and picks the best. Choose H.264, HEVC or AV1, up to 480 fps.
- **Game and microphone audio** as separate tracks, from the devices you choose.
- **Hotkeys:**
  - **F8** saves a clip.
  - **F9** takes a screenshot.
  - **F7** marks a moment so you can find it later.
  - Every hotkey can be rebound. `rerunsctl save` does the same from a script or a Stream Deck.
- **Recovers by itself** if the capture fails mid-game, and handles windows that change size.
- **HDR displays** (Windows): an HDR compatibility mode tone-maps the picture so clips don't look washed out. Capturing the game window itself in HDR is available as an experimental option.
- **In-game popup** on Windows ("Ready to record", "Clip saved") that never takes focus from the game. Notifications and a save sound are available on both platforms, and the sound can be your own file.

## Your clips

- **Games view:** your games with their Steam artwork, and your clips grouped by play session.
- **All clips:** search, sort, filter by game, favourite or label, and select many clips to delete at once. A delete can be undone.
- **Viewer:** frame stepping, playback speed, markers on the timeline, and keyboard shortcuts for everything (press `?`).
- **Trimmer:** cut a clip and set the game and mic volume. Size presets fit a render under Discord's upload limits (10 MB, 50 MB or 500 MB).
- **Storage cap:** old clips are cleared automatically when you set a limit, and go to the Trash by default.

## Updates

Reruns checks for new versions in the background and shows **Update and restart** when one is out. Nothing downloads until you press it. The check can be turned off in Settings → General.

## Known limitations

- **X11 isn't supported on Linux.** Use a Wayland session.
- **On GNOME, Hyprland and other non-KDE desktops** the whole screen is recorded, not just the game window, after a one-time screen-share prompt.
- **HDR window capture is experimental.** If it doesn't work on your PC, turn it off and HDR compatibility mode is used instead.
- **Logs**, for reporting problems:
  - Windows: `%LOCALAPPDATA%\gg.reruns.app\logs`
  - Linux: `~/.local/share/reruns/logs`
