Fixes for Windows.

## Game detection

- Only games are recorded: anything installed by Steam, Epic, Riot, GOG, Ubisoft, EA, Battle.net or the Xbox app, or on Windows' own list of games.
- The emoji panel, Snipping Tool and Game Bar are no longer detected as games.
- Remove old entries with the × on a game card. A game that's missed can be added with Game Bar (Win+G): "Remember this is a game".

## Recording

- If the graphics encoder refuses to start, Reruns switches to another one instead of retrying.
- With "Capture the window in HDR" on, only the game window is recorded, even when HDR capture can't start.
- HDR window capture frees its GPU memory as soon as a recording stops.
- On PCs with integrated graphics, capture runs on the same GPU as the encoder.

Bugs: [open an issue](https://github.com/lpears0n/reruns/issues) with your log (`%LOCALAPPDATA%\gg.reruns.app\logs`).
